OVERVIEW

Interactive scene reconstruction

NeoWorld-Pro formulates monocular scene reconstruction as a procedural programming task for interactive 3D environments.

Multimodal large language models translate a single RGB image into executable programs that describe object geometry, articulated parts, physical properties, and scene layout. This representation supports editing and interaction, alongside visual reconstruction.

A physics-in-the-loop mechanism executes the generated programs in a physics engine and refines them using simulation feedback. The resulting scenes support stable stacking, fine-grained manipulation, and articulated object interactions.

02

METHOD

Scene programs and physics feedback

The reconstruction pipeline connects visual observations, executable scene descriptions, and simulation feedback.

Programmable representation

Geometry and articulation are defined in code. Object structure and scene layout can be inspected, changed, and regenerated.

Physics-in-the-loop refinement

Generated scenes are executed in a physics engine. Simulation feedback guides updates to improve physical executability.
