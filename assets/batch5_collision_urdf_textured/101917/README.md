# 101917 — 带材质的可动 URDF

入口：`101917.urdf`。复制时请保留完整目录，包括 `meshes/` 与 `textures/`。

可动关节 8 个；原几何、关节树、轴向及限位均保持不变。
PNG 贴图 0 张。没有 PNG 的模型采用原始纯色材质。

使用支持 OBJ/MTL 材质与 UV 贴图的 URDF 查看器。单材质 visual 同时声明了 URDF color/texture；多材质网格由 MTL 分配材质。

颜色贴图已经导出；Blender 的程序化凹凸、粗糙度和发光效果可能因查看器而不同。
尺寸仍为归一化模型单位，真实尺寸未知。惯量和碰撞模型未新增，effort/velocity 为零占位值。
